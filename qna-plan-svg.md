## 1. Icon System & Style

- **Chosen System:** **Enhanced Custom `Icon.tsx`**
- **Style & Scale:** Clean 1.5px/2px stroke icons with `currentColor`, round linecaps/joins, optically centered on a 16×16 canvas scale (`w-4 h-4` default, `shrink-0`), following Lucide React stroke design standards.
- **Rationale:** Keeps the app bundle lightweight and dependency-free while expanding the existing `src/components/ui/Icon.tsx` SVG paths to support all required glyphs (status icons, format icons, action glyphs) with zero regression.

---

## 2. Enhancement Scope

- **Selected Scope:** **All 3 Target Scopes**
  1. **Interactive Action Triggers:** Sidebar expand/collapse, New Session triggers, Add/Delete project actions, Session More menu, Model picker dropdown, Dynamic Agent toggle, Reasoning toggle, Stage prompt edit button, Q&A user/assistant message actions, Stage composer submit, and Attachment file triggers.
  2. **Data & Status Indicators:** Provider status chip (connected/error/disconnected icons), Clamped context warning, Model capability chips, Step rail check/number dots, Section disclosure accordions, and New Session methodology selection radio cards.
  3. **Clipboard & Quick Actions:** Copy stage content, Copy Q&A answer, Regenerate stage/answer (with active spinning animation), Longer/Shorter/Deeper stage modifiers, Export format buttons (format-specific icons), Clear key, and Remove provider/project/session actions.

## 3. Features to Add

### In-Scope (Additive & Presentation-Only)
- **Accessible Tooltip Infrastructure:** Integrate `@radix-ui/react-tooltip` (or custom Portal-backed floating tooltip component) wrapped in a top-level `<TooltipProvider>` to deliver keyboard-focusable, accessible tooltips across all 36 target slots.

- **Format-Specific Export Icons:** Replace generic download icons with format-matched glyphs (`FileText`, `Archive`, `FileSpreadsheet`, `FileDown`, `Code2`).

### Out-of-Scope (Logic-Changing — Deferred)
- *Global Keyboard Shortcut Re-binding:* Modifying global keyboard listener logic or shortcut event handlers in application components.
- *Data Model or API Changes:* Any changes to session persistence, API payloads, or server streaming protocol.

## 4. GitHub Skill / Reference

- **Selected Skill/Reference:** **Lucide Icon Guidelines (`lucide_guidelines`)**
- **Purpose:** Serve as the design guideline for icon stroke consistency, optical centering, bounding box alignment, and accessibility markup (`aria-hidden="true"` on decorative icons) when expanding `Icon.tsx` and adding tooltips.

---

## 5. Notes

- All tooltips in constrained parent containers (sidebar rail, scrollable stage deck, popover dropdowns) must use **Portal** positioning to bypass clipping traps.
- All SVG elements inside flex/grid containers must include `shrink-0` to avoid layout reflow or squishing.
- Zero source code logic is modified during planning; implementation will strictly adhere to zero-regression guidelines.
